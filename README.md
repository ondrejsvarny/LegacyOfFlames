# Legacy of Flames

**Legacy of Flames** is a 2D pixel-art platformer game developed for both **PC (Windows)** and **Mobile (Android)** devices. Players control a small dragon navigating through various levels, overcoming obstacles, battling enemies and challenging bosses, collecting coins, and purchasing character upgrades in an interactive shop.

This project was developed as a graduation project at the Secondary Technical School of Electrical Engineering (SPŠE Komenského 44, Košice).

## Key Features

* **Cross-Platform Support**: Fully playable on PC with customizable control schemes and Android with intuitive touch controls.

* **Dynamic Movement & Mechanics**: Includes crouching, double jumping, ladder climbing, wall jumping, and interactive checkpoints.

* **Combat System**:

  * **Fireball**: Ranged attack consuming energy.

  * **Dash**: High-speed movement phase that damages enemies and doubles as a mobility/evasion tool.

* **Shop & Upgrade System**: Spend collected coins to permanently upgrade maximum health, attack damage, cooldown speeds, and projectile velocity.

* **Diverse Enemies & Boss Battles**: Enemies with varied AI patterns (patrolling, chasing, ranged attacks) and multi-phase bosses driven by a Finite State Machine (FSM).

* **Interactive Environment**: Dynamic platforms (moving, falling), physics objects, traps, switches, doors, chests, NPC dialogues, and multi-layered parallax backgrounds.

* **Save System**: Automatic encryption and persistent saving of unlocked levels, coins, and purchased upgrades.

## Built With

* **Engine**: Godot Engine 4.4

* **Scripting Language**: GDScript

* **Graphics**: Pixel Art created/edited via Piskel and Pixil

* **Mobile Export**: Android Studio & Android SDK
